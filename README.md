# Agentic Intelligence Workspace

> Under active development. A tested FastAPI backend currently provides `GET /health` plus deterministic CSV/XLSX ingestion, inspection, profiling, transformation, joins, aggregation, and CSV/XLSX export APIs.

This project aims to turn natural-language goals over structured data and unstructured documents into verified, reproducible workflows and useful artifacts.

Its four permanent technical pillars are:

1. Agentic Systems
2. Retrieval & Knowledge
3. Data Intelligence
4. Trustworthy AI Engineering

The current phase provides a typed, deterministic structured-data engine with pytest coverage and in-memory artifact generation. See [`docs/ROADMAP.md`](docs/ROADMAP.md) for verified progress and planned work.
