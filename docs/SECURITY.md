## Status

This document tracks the threat model, implemented security controls, residual risks, and deployment limitations for V1.

Controls marked as implemented are enforced by the current codebase and covered by targeted tests where applicable. Items described as design requirements or limitations remain future work.

V1 is designed for single-user, local, or controlled deployment. It is not intended for sensitive multi-user production use because authentication, authorization, tenancy, retention policies, and several deployment-hardening controls remain out of scope.
